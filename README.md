# NovaPlan

برنامه‌ریز روزانه با گرافیک نئونی، سیستم XP و استریک — ساخته‌شده با Flutter.

## ویژگی‌ها
- بلوک‌های زمانی با رنگ‌بندی نئونی بر اساس دسته (گرامر، شنیداری، کار، شرکت، سایر)
- سیستم XP: با هر بلوک تکمیل‌شده امتیاز می‌گیری، با تکمیل کل روز پاداش اضافه می‌گیری
- استریک روزانه با آیکون شعله، فقط وقتی همه‌ی بلوک‌های یک روز کامل بشن افزایش پیدا می‌کنه
- صفحه‌ی آمار ۷ روز اخیر: ساعت برنامه‌ریزی‌شده در برابر تکمیل‌شده، به تفکیک دسته
- همه‌چیز محلی و آفلاین ذخیره می‌شه (SharedPreferences) — نیازی به سرور نیست

## ساختار پروژه
فقط `lib/` و `pubspec.yaml` نگه‌داری می‌شن (شبیه ساختار WordQuest). پوشه‌ی
`android/` و `ios/` عمداً commit نشده — ورک‌فلوی گیت‌هاب اکشن هر بار یک پروژه‌ی
تازه با `flutter create` می‌سازه و فایل‌های `lib/` رو داخلش کپی می‌کنه، بعد APK
رو می‌سازه.

## ساخت روی گیت‌هاب (بدون نیاز به نصب Flutter روی سیستم خودت)
1. یک ریپازیتوری جدید در گیت‌هاب بساز.
2. تمام فایل‌های این پوشه رو (شامل `.github/workflows/build.yml`) push کن.
3. برو به تب **Actions** در ریپو — ورک‌فلو خودش اجرا می‌شه.
4. بعد از اتمام (چند دقیقه)، روی اجرای موفق کلیک کن و از بخش **Artifacts**،
   فایل `novaplan-apk` رو دانلود کن. داخلش `app-release.apk` هست.
5. APK رو روی گوشی اندرویدت نصب کن (شاید لازم باشه نصب از منابع ناشناس رو
   فعال کنی).

## ساخت محلی (اگه Flutter نصب داری)
```bash
flutter create --platforms=android temp_app
cp -r lib/. temp_app/lib/
cp pubspec.yaml temp_app/pubspec.yaml
cd temp_app
flutter pub get
flutter build apk --release
```

## قدم بعدی‌های پیشنهادی
- اضافه کردن drag & drop واقعی برای جابه‌جایی بلوک‌ها
- پکیج `flutter_local_notifications` برای یادآوری واقعی (نیاز به ویرایش دستی
  AndroidManifest.xml دارد، پس در این نسخه فقط تنظیمش ذخیره می‌شه)
- افکت particle موقع تکمیل یک بلوک یا رسیدن به لِوِل جدید
